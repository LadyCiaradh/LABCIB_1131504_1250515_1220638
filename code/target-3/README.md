# Target 3 - Strings

Este target **não usou script próprio**. A extração das strings do firmware foi feita com a ferramenta-padrão `strings` (Sysinternals, no Windows), que é o primeiro passo típico de análise de firmware. A inspeção (procurar credenciais, offsets e blobs) foi manual, no editor.

- Comando usado e passos de inspeção: ver `TARGETS/target-3/README.md`.
- Evidências (output completo e lista anotada): `TARGETS/target-3/` (`strings-22.txt` e `strings-38.txt`; a lista anotada de assets está em `TARGETS/target-3/README.md`).
